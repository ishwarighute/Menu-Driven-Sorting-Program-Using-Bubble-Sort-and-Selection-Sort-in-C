# Menu-Driven Sorting Program

## Project Overview

The Menu-Driven Sorting Program is a simple C language project that allows users to sort a list of numbers using different sorting algorithms.

The program provides two sorting techniques:

1. Bubble Sort
2. Selection Sort

Users can select their preferred sorting method through a menu.

## Features

- Accepts numbers from the user.
- Provides a menu-driven interface.
- Implements Bubble Sort.
- Implements Selection Sort.
- Displays sorted numbers in ascending order.
- Allows users to exit the program.

## Technologies Used

- Programming Language: C
- Code Editor: Visual Studio Code
- Compiler: Online C Compiler

## How to Run

1. Open the project in VS Code.
2. Open main.c.
3. Copy the code into an online C compiler.
4. Select C language.
5. Click Run.
6. Enter numbers and select a sorting method.

## Sorting Algorithms

### 1. Bubble Sort

Bubble Sort compares adjacent elements and swaps them if they are in the wrong order.

### 2. Selection Sort

Selection Sort finds the smallest element from the unsorted portion and places it in the correct position.
